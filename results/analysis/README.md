## Conventions

- Attack-family rules are in `crossids.analysis.ATTACK_FAMILIES`; `other` is used only for names listed in `EXPLICIT_OTHER` or unmatched names (the unit test enforces this for every cached attack type).
- Figures follow one palette: categorical colours in fixed order (never cycled), a diverging blue-red scale centred at 0.5 for feature AUC, and a sequential blue scale for recall and transfer ROC-AUC.
- Seeds are averaged within a scenario before scenario-level statistics are computed.
